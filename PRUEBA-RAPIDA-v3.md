# ⚡ PRUEBA RÁPIDA - ACCESO IA 3.0

## 🎯 PARA PROBAR EN 2 MINUTOS

---

### 1️⃣ **Reiniciar Servidor** (30 segundos)

```bash
# En la terminal:
Ctrl + C
npm run dev
```

Espera: `✓ Ready in X.Xs`

---

### 2️⃣ **Probar Markdown** (30 segundos)

```
1. Abre: http://localhost:3000
2. Click en "🤖 Acceso IA"
3. Escribe: "Explícame las fracciones con ejemplos"
4. Enviar
5. ¡Verás texto con negritas, listas y código!
```

---

### 3️⃣ **Probar Examen Interactivo** (1 minuto)

```
1. En el chat, escribe:
   "Hazme un examen de 5 preguntas de matemáticas"

2. Enviar

3. ¡El chat se transforma en examen!

4. Click en respuestas → Verde o roja

5. Automáticamente avanza cada 1.5s

6. Al final: Nota de media sobre 10
```

---

### 4️⃣ **Ver Jorge en el Equipo** (30 segundos)

```
1. Ve a: http://localhost:3000/admin
2. Click en "Miembro del equipo"
3. ¡Ahí está Jorge Ballesteros!
4. Sube su foto
5. Publish
6. Ve a: http://localhost:3000/sobre-nosotros
```
